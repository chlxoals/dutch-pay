# 한 장 기획서: 더치페이 정산기

## 한 줄 소개
모임에서 쓴 돈을 참여자 수대로 나눠 한 사람당 낼 금액을 바로 알려주는 모바일 웹 앱.

## 해결할 문제
식당이나 카페에서 계산 후 "한 명당 얼마지?"를 계산기로 따로 두드리는 번거로움을 없앱니다.

## 사용자
친구, 동기, 동아리 등 함께 모임을 갖는 사람들. 설명서 없이 휴대폰으로 바로 사용.

## 핵심 기능 (1주차)
1. 참여자 이름 추가/삭제
2. 총 금액 입력
3. 1인당 금액 계산 (10원 단위 내림, 남는 금액은 첫 번째 사람이 부담)

## 이후 계획
- 2주차: 항목별 정산(사람마다 먹은 것이 다를 때), 휴대폰 실사용 테스트와 개선
- 3주차: 결과 공유(복사), 디자인 정리, 발표 준비

## 기술/배포
- HTML/CSS/JavaScript 단일 페이지, 서버 코드 없음
- GitHub Pages 무료 호스팅으로 상시 접속
- 접속 주소(예정): https://chlxoals.github.io/dutch-pay/

## 성공 기준
- 휴대폰 화면에서 불편 없이 입력부터 결과까지 사용 가능
- 무료 서버에서 상시 접속 가능
