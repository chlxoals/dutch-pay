# 한 장 기획서: 여행·모임 다통화 정산 서비스 (모바일 웹)

## 형태
모바일 지원 웹 (HTML/CSS/JavaScript, GitHub Pages 무료 호스팅, 서버 없이 브라우저에서 동작)
접속 주소: https://chlxoals.github.io/dutch-pay/

## 한 문장 설명
해외여행이나 모임에서 여러 날, 여러 통화로 쌓이는 지출과 환전을 환율에 맞춰 원화로 환산하고, 공동경비와 예산까지 관리하면서 "누가 누구에게 얼마"를 최소 송금으로 정리해 주는 정산 서비스.

## 해결할 문제
해외여행에서는 사람마다 환전한 시점과 환율이 다르고 현지 통화와 원화가 섞여 결제되어 누가 얼마를 더 냈는지 계산하기 어렵습니다. 공동경비를 모아 쓰는 경우에도 남은 돈을 얼마씩 돌려줘야 하는지, 예산이 얼마나 남았는지 메신저와 메모만으로는 관리하기 번거롭고 실수가 생깁니다.

## 사용자
친구, 동기, 동아리, 여행 동행의 총무와 참여자. 설명서 없이 휴대폰으로 사용.

## 핵심 기능 (1개)
- 여행·모임 다통화 정산: 모임(여행)을 만들고 날짜별로 지출을 쌓습니다. 지출마다 통화(원, 엔, 달러, 유로 등), 결제한 사람, 함께한 사람, 인분 비율을 지정하면 통화별 환율로 원화에 환산해 멤버별 최종 잔액과 최소 송금 목록을 계산합니다. 환율은 직접 입력이 기본이며 지출마다 다른 환율을 적용할 수 있습니다.

## 부가 기능 (3개)
1. 환전·환율 관리: 환전한 원화 금액과 받은 외화를 입력하면 실제 적용 환율을 자동 계산하고, 여러 사람의 환전 내역을 평균 환율로 묶어 정산에 사용. 나라별 환율 화면(달러, 엔, 파운드, 유로 등 통화별 창)에서 외화 금액을 입력하면 바로 원화로 환산해 보여주는 환율 계산기 제공. 선택 기능으로 공개 환율 조회를 통해 기준 환율을 불러오고, 마지막 조회 값을 휴대폰에 저장해 오프라인에서도 사용(기준 시각 표시).
2. 통계와 시각화: 날짜별 일일 지출과 하루 평균, 카테고리별(식비, 교통, 숙박, 쇼핑, 기타), 사람별 지출 그래프와 통화별 합계를 표시. 카테고리는 버튼 한 번 또는 항목 이름 키워드 규칙으로 자동 추천해 입력 부담을 최소화.
3. 여행 자금 관리: 여행 전체의 돈을 모으고, 지키고, 마무리하는 기능 묶음.
   - 공동경비: 출발 전 각자 낸 금액을 기록하고, 지출 입력 시 "공동경비로 결제"를 체크하면 공동경비 잔액에서 차감되며 개인 간 송금에는 들어가지 않음. 여행이 끝나면 남은 금액을 낸 비율대로 돌려줄 금액으로 계산. 어떤 지출을 공동경비로 쓸지는 멤버 간 합의에 따르며, 앱은 모두가 함께 쓰는 지출에 쓰기를 권장하는 안내만 표시.
   - 예산 관리: 여행 예산을 정하면 남은 예산과 남은 일수 기준 하루 권장 지출액을 표시하고, 예산의 80%를 넘으면 경고.
   - 송금 완료 체크: 최종 정산의 송금 항목마다 완료를 체크해 아직 보내지 않은 사람을 한눈에 보여주고, 모두 완료되면 정산 끝으로 표시. 정산 결과는 카톡용 문구, 계좌 복사, 토스 송금 링크로 공유.

## 완료 기준 (3개)
1. 휴대폰에서 여행 만들기, 외화 지출 입력, 환율 적용, 최종 정산까지 설명 없이 끝낼 수 있다.
2. 통화와 환율이 섞여도 원 단위 반올림 후 부담금의 합이 총 지출과 정확히 일치한다.
3. 공동경비를 낸 사람별 금액과 공동경비 지출을 입력하면, 남은 잔액이 맞게 표시되고 여행 종료 시 돌려줄 금액의 합이 잔액과 일치한다.

## 안 할 것 (3개)
1. 실제 결제, 송금, 환전 처리 (계산과 안내, 링크 연결까지만)
2. 로그인, 회원가입, 서버 저장 (데이터는 사용자의 휴대폰 브라우저에 저장하고 필요 시 링크로 공유)
3. 실행 중 AI API 호출 (공개 환율 조회는 AI가 아닌 단순 데이터 조회로 선택 기능)

## 개발 계획 (3주)
- 1주차 (완료): 항목별 정산, 비율 나누기, 최소 송금 계산, 이력 저장, 링크 공유, 송금 연결, GitHub Pages 배포
- 2주차: 여행·모임 구조(여러 날, 카테고리), 다통화 지출 입력과 환율 적용, 환전 기록과 평균 환율, 나라별 환율 화면과 환율 계산기, 통계 그래프
- 3주차: 여행 자금 관리(예산 → 송금 완료 체크 → 공동경비 순으로 구현), 항목 수정과 되돌리기, 휴대폰 실사용 테스트와 개선, 사용 안내와 예시 체험, 회고 정리
- 시간이 남으면: 오프라인 사용(홈 화면 설치, PWA), 여행 결산 이미지, 데이터 내보내기와 백업, 팁·할인·세금 환급 반영

## 위험과 대비
- 환율 자동 조회가 막히거나 오프라인이면 직접 입력과 마지막 저장 값으로 동작한다(직접 입력이 기본).
- 공동경비 계산이 막히면 예산 관리와 송금 완료 체크를 먼저 완성해 부가 3의 기준을 채운다.
