# 한 장 기획서: 여행·모임 다통화 정산 서비스 (모바일 웹)

## 형태
모바일 지원 웹 (HTML/CSS/JavaScript, GitHub Pages 무료 호스팅 + 데이터 공유용 무료 서버)
접속 주소: https://chlxoals.github.io/dutch-pay/

## 한 문장 설명
해외여행이나 모임에서 여러 날, 여러 통화로 쌓이는 지출과 환전을 환율에 맞춰 원화로 환산하고, 멤버별 최종 잔액과 최소 송금을 한 번에 정리해 주는 정산 서비스.

## 해결할 문제
해외여행에서는 사람마다 환전한 시점과 환율이 다르고, 현지 통화와 원화가 섞여 결제되어 누가 얼마를 더 냈는지 계산하기 어렵습니다. 기억과 메모에 의존하면 실수와 불필요한 송금이 생깁니다.

## 사용자
친구, 동기, 동아리, 여행 동행의 총무와 참여자. 설명서 없이 휴대폰으로 사용.

## 핵심 기능 (1개)
- 여행·모임 다통화 정산: 모임(여행)을 만들고 날짜별로 지출을 쌓습니다. 지출마다 통화(원, 엔, 달러, 유로 등), 결제한 사람, 함께한 사람, 인분 비율을 지정하면 통화별 환율로 원화에 환산해 멤버별 최종 잔액과 최소 송금 목록을 계산합니다. 환율은 직접 입력이 기본이며 지출마다 다른 환율을 적용할 수 있습니다.

## 부가 기능 (3개)
1. 환전·환율 관리: 환전한 원화 금액과 받은 외화를 입력하면 실제 적용 환율을 자동 계산하고, 여러 사람의 환전 내역을 평균 환율로 묶어 정산에 사용. 선택 기능으로 공개 환율 조회를 통해 기준 환율을 불러옴.
2. 통계와 시각화: 날짜별, 카테고리별(식비, 교통, 숙박 등), 사람별 지출 그래프와 통화별 합계를 표시.
3. 실시간 공유방과 결과 공유: 링크나 QR로 방에 입장해 각자 휴대폰에서 함께 입력하고 변경이 실시간 반영(무료 서버 연동). 카톡용 정산 문구, 계좌 복사, 토스 송금 링크 제공.

## 완료 기준 (3개)
1. 휴대폰에서 여행 만들기, 외화 지출 입력, 환율 적용, 최종 정산까지 설명 없이 끝낼 수 있다.
2. 통화와 환율이 섞여도 원 단위 반올림 후 부담금의 합이 총 지출과 정확히 일치한다.
3. 두 대 이상의 휴대폰이 같은 방에서 입력과 변경을 서로 실시간으로 확인할 수 있다.

## 안 할 것 (3개)
1. 실제 결제, 송금, 환전 처리 (계산과 안내, 링크 연결까지만)
2. 이메일 로그인과 회원가입 (방 링크와 닉네임으로 입장)
3. 실행 중 AI API 호출 (공개 환율 조회는 AI가 아닌 단순 데이터 조회로 선택 기능)

## 개발 계획 (3주)
- 1주차 (완료): 항목별 정산, 비율 나누기, 최소 송금 계산, 이력 저장, 링크 공유, 송금 연결, GitHub Pages 배포
- 2주차: 여행·모임 구조(여러 날, 카테고리), 다통화 지출 입력과 환율 적용, 환전 기록과 평균 환율, 항목 수정과 되돌리기, 통계 그래프, 홈 화면 설치(PWA)와 오프라인 사용
- 3주차: 서버 연동 실시간 공유방, 여러 휴대폰 테스트, 사용 안내와 예시 체험, 회고 정리
- 시간이 남으면: 팁, 할인, 세금 환급 반영

## 위험과 대비
- 환율 자동 조회가 막히거나 오프라인이면 직접 입력으로 동작한다(직접 입력이 기본).
- 서버 연동이 막히면 링크 공유(서버 없음) 방식으로 대체하고, 2주차까지의 기능은 유지한다.
